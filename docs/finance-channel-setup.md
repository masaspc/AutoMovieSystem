# 金融チャンネル編集方針の設定

`/settings` の「チャンネル別編集方針」で、金融チャンネルだけに安全方針と
トレンドフィードを設定する。未設定チャンネルの挙動は変わらない。

## 推奨ポリシー例

- トーン: 落ち着いた丁寧解説。専門用語は初出時に日常語へ言い換える
- 対象視聴者: NISA・iDeCoをこれから学ぶ投資未経験者
- 禁止事項:
  1. 個別銘柄・個別商品の購入や売却を推奨しない
  2. 利回り・価格・値動きを断定または予測しない
  3. 売買タイミングや投資判断を助言しない
  4. 制度・公的情報は官庁名と発表日を明記し、一次情報URLを出典にする
- 免責文: `本動画は制度に関する一般的な情報提供を目的とし、特定商品の推奨や投資助言ではありません。投資判断はご自身の責任で行ってください。`

## フィード例

- 金融庁 新着情報: `https://www.fsa.go.jp/fsaNewsListAll_rss2.xml`
- 厚生労働省 新着情報: `https://www.mhlw.go.jp/stf/news.rdf`
- 財務省: [公式RSS一覧](https://www.mof.go.jp/about_mof/rss/index.html)から用途に合うURLを選ぶ

金融庁と厚生労働省の公式RSS案内ページで現行URLと利用条件を確認してから登録する。
日経マネー等の民間媒体は、公開RSSの提供状況と利用規約が変わり得るため、媒体の公式案内で
自動取得・商用利用が許可されたフィードだけを登録する。サイト本文のスクレイピングは行わない。

本システムが保存・台本へ渡すのは、従来どおり記事の見出し、URL、配信元、200字以内の
フィード要約だけである。記事本文は取得・保存・転載しない。
